#Google Form Automation Suite

Overview:
This project involves automating a google form, end-to-end, with a variety of different inputs such as checkboxes, dropdowns, radio-buttons and more.

Scope of work:

Automated the following Flow:
    1.Navigating to this google form.
    2.Filling in text in the a text box
    3.Doing date-time operations to fill in a dynamic value in a text-area.
    4.Choosing experience from a radio-button input
    5.Choosing certain skills from a checklist
    6.Choosing a value from the dropdown menu
    7.Dynamically calculating the date
    8.Providing the time dynamically
    9.Submitting the form and printing the final message
